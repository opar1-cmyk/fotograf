# fotograf

Eğitim sistemi, rol ve sorumluluklar hakkında bilgilendirici bir web sitesidir.

## İçerik

- Zaman çizelgesi
- Rol ve sorumluluklar
- Gruplar ve değişimleri
- Kariyer yolları

## Görüntüleme

`index.html` dosyasını tarayıcıda açarak siteyi görüntüleyebilirsiniz.

## Kullanım

Siteyi GitHub Pages üzerinde yayınlamak için:
1. Repository ayarlarına gidin
2. Pages seçeneğini açın
3. main branch'i seçin
4. Kaydedin
